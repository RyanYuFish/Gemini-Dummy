## 阅读建议

- **只想跑起来看画面** → `../README.md` §1 快速开始。
- **想接手某个课题** → `../README.md` §8 课题表 → 对应章节。
- **想理解「为什么之前一直黑屏/花屏」** → §41、§42。
- **想加一个数据字段** → §41.3 的 prop 表 + `tools/probe_prop.py`（身份载荷法）。
- **想改模型** → `tools/build_model.py` 的注释（macOS codesign 坑）+ `KERNEL-DISPLAY-RE.md`。
